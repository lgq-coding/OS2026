本文件按时间顺序汇总 Lab1 期间使用的 Prompt，用于记录需求、目的和验证结果。

## Prompt 1：实验环境配置

**Prompt 内容：**

> OS2026 是我的操作系统作业文件夹，请查看 `3_startdash.md`，说明哪些内容需要在 WSL 中配置。

**使用目的：**确认 RISC-V 工具链、QEMU 和 `PATH` 的配置要求。

**结果：**确认需要安装 RISC-V 交叉工具链、配置 `RISCV` 与 `PATH`，并安装 `qemu-system-riscv64`。
